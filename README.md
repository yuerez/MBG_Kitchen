# MBG Experience (Roblox)

Repository untuk proyek game Roblox **MBG Experience** (Place ID: `86603539295376`).

## Struktur Proyek (Rojo)

- `src/server/` -> `ServerScriptService`
  - `LeaderstatsManager.server.luau`: Mengatur `leaderstats` pemain (`Coins`, `Paket MBG`) serta atribut dasar (`MaxBagCapacity`, `CookTime`).
- `src/client/` -> `StarterPlayer.StarterPlayerScripts`
- `src/shared/` -> `ReplicatedStorage`
- `default.project.json` -> Konfigurasi Rojo project
